# 🚀 BikinQR - Neo-Brutalist QR Generator

Platform pembuat QR Code premium dengan fitur Dinamis, Analytics, dan Gallery.

## 📖 Dokumentasi Lengkap
Silakan baca [GUIDE.md](./GUIDE.md) untuk panduan lengkap fitur dan cara penggunaan.

## 🌟 Fitur Unggulan
- **vCard Dinamis:** Edit data tanpa cetak ulang.
- **Smart QR:** WiFi, Maps (dengan Map Picker), dan Link.
- **Gallery:** Riwayat QR & fitur Restore.
- **Analytics:** Grafik scan harian.
- **Kustomisasi:** Dots, Corners, Colors, & Custom Logo.

## 🚀 Quick Start
1. `npm install` di root dan folder `client`.
2. Setup Supabase dengan `supabase_migration.sql`.
3. Jalankan server: `node server.js`.
4. Jalankan frontend: `cd client && npm run dev`.
